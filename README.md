# Гамбит

**«Гамбит»** — стратегическая коллекционная карточная игра (CCG) для двух игроков, выполненная в стилистике вселенной «Ведьмак». Проект разработан в рамках курсовой работы и поддерживает локальные матчи, онлайн-сражения через виртуальные частные сети (VPN), встроенный конструктор колод и сохранение игровой статистики.

## ✨ Особенности
- **Дуэли 1 на 1:** Сражения до двух побед в раундах (Best of 3).
- **Двухрядное поле боя:** Разделение на позиции ближнего и дальнего боя.
- **Встроенный конструктор колод:** Формирование собственной сборки из доступного пула карт.
- **Кроссплатформенность и гибкость запуска:** Поддержка запуска через интерпретатор Python (`launcher.py`) или готовый бинарный файл (`launcher.exe`).

## 📜 Правила и механика игры

### Основные понятия
* **Карта** — игровая единица, обладающая параметром силы и уникальными свойствами/способностями.
* **Колода** — набор карт (стандартно от 20 до 25 карт), используемый игроком в течение матча.
* **Ряды поля боя:**
  * *Ближний бой* — ряд для размещения пехоты и бойцов авангарда.
  * *Дальний бой* — ряд для стрелков и осадных отрядов.

### Ход матча
1. **Первый раунд:**
   * Игроки ходят строго по очереди.
   * За один ход можно либо **выложить одну карту** в соответствующий ряд, либо **спасовать** (завершить участие в текущем раунде).
   * Раунд заканчивается, когда спасовали оба игрока.
2. **Последующие раунды:**
   * Проигравший раунд игрок начинает следующий раунд первым.
   * Перед 2-м и 3-м раундами каждый игрок автоматически добирает по **5 дополнительных карт**.
3. **Условия победы:**
   * Раунд выигрывает игрок, набравший наибольшую суммарную силу карт на своей половине поля к моменту паса обоих участников.
   * Матч завершается победой игрока, выигравшего **2 раунда**.
   * Ничья присуждается в случае равного счёта по раундам (1:1) и ничьей по очкам силы в третьем раунде.

### Стратегия и тактика
* **Блеф и тайминг:** Иногда тактически выгодно спасовать в первом раунде, заставив соперника истратить ценные ресурсы.
* **Контроль руки:** Не выкладывайте все сильные карты сразу — берегите комбинации на финальный раунд.
* **Оптимизация колоды:** Подбирайте синергирующие между собой карты и сохраняйте минимально допустимый объём колоды для максимальной стабильности добора.

## 🚀 Установка и запуск

Склонируйте репозиторий на локальную машину:
```bash
git clone https://github.com/SPOiBD3sem/gambit_game.git
cd gambit_game
```

> **Примечание:** Если у вас не установлен Python, вы можете запускать игру через `launcher.exe`. Если вы запускаете проект из исходников — используйте команду `python launcher.py`.

---

### Способ 1. Локальный запуск (Localhost)
*Подходит для тестирования или игры в рамках одного компьютера/локальной сети.*

1. Оба участника запускают `launcher.py` (или `launcher.exe`).
2. **Игрок 1 (Хост):** Нажимает кнопку **«Хост сервера»** и ожидает инициализации.
3. После запуска сервера оба игрока выбирают в меню **«Присоединиться к игре»**.
4. В строке адреса оставляют значение по умолчанию: `localhost`, затем подтверждают подключение.
5. В открывшемся лобби оба игрока нажимают **«Готово»**. Игра начнётся автоматически.

---

### Способ 2. Сетевая игра через Интернет (Radmin VPN)
*Используется для игры с разных компьютеров через виртуальную локальную сеть.*

1. Оба игрока скачивают и запускают программу [Radmin VPN](https://www.radmin-vpn.com/ru/).
2. **Хост:**
   * В меню Radmin VPN выбирает: `Сеть` ➔ `Создать сеть`.
   * Задает имя сети и пароль, после чего сообщает их второму игроку.
3. **Клиент:**
   * В меню Radmin VPN выбирает: `Сеть` ➔ `Присоединиться к сети` и вводит данные сети хоста.
4. **Подключение к матчу:**
   * Клиент находит хоста в списке устройств Radmin VPN и **копирует его виртуальный IP-адрес** (например, `26.x.x.x`).
   * **Хост** запускает `launcher.py`, нажимает **«Хост сервера»**, затем **«Присоединиться к игре»** и подключается к `localhost` (свой IP хост не меняет).
   * **Клиент** запускает `launcher.py`, нажимает **«Присоединиться к игре»**, стирает `localhost`, вставляет скопированный **IP-адрес хоста** и подтверждает вход.
5. После появления обоих участников в комнате каждый нажимает **«Готово»**.

## 🖥 Интерфейс главного меню
* **Хост сервера** — запуск локального игрового сервера прямо из интерфейса клиента.
* **Присоединиться к игре** — окно ввода IP-адреса для подключения к активному серверу.
* **Конструктор колоды** — панель выбора карт и настройки активной боевой колоды.
* **Настройки отображения** — переключение разрешения, оконного режима, полноэкранного режима и режима без рамок.

## ❓ Часто задаваемые вопросы (FAQ)

**Q: Можно ли добавить собственную новую карту?**  
**A:** Нет, создавать свои карты нельзя. Выбор осуществляется строго из доступного каталога карт, распределённых по 5 страницам внутри «Конструктора колоды» (переключение кнопками «Вперёд» и «Назад»).

**Q: Что делать, если клиент завис или не подключается к хосту?**  
**A:** 
1. Перезапустите игровой клиент на обеих машинах.
2. Проверьте статус подключения в Radmin VPN (индикатор рядом с именем соперника должен быть зеленым).
3. Проверьте настройки брандмауэра Windows / антивируса — входящие сетевые соединения для игры и Python не должны блокироваться.
